
# 🏃‍♂️ 88 리플레이 (88 Replay) - 88서울올림픽 동작 따라하기

> **"내가 그 순간의 선수가 되어본다"**[cite: 1]  
> 88서울올림픽 당시 선수들의 경기 영상을 보면서 웹캠으로 동작을 따라 하고, 그 유사도(정확도)를 실시간으로 측정해보는 인터랙티브 체험형 웹 서비스입니다[cite: 1]. 

2026 공공데이터 활용 경진대회(국민체육진흥공단 주관) 출품작입니다[cite: 1].

---

## 📢 프로젝트 개요 (Overview)

단순히 옛 영상을 감상하는 것을 넘어, 역사적 기록을 젊은 세대에게 재미있게 전달하고 공공데이터의 새로운 활용 사례를 제시하는 것을 목표로 합니다[cite: 1]. 

* **활용 데이터**: 공공데이터포털 - 서울올림픽기념국민체육진흥공단_올림픽자료실 사진동영상 정보 API[cite: 1]
* **타깃 사용자**: 
  * 공모전 심사위원 (데모/시연 대상)[cite: 1]
  * 스포츠/레트로 콘텐츠에 관심 있는 일반 사용자 및 88올림픽을 기억하는 가족 단위 체험객[cite: 1]

---

## ✨ 주요 기능 (Key Features)

### 1. 듀얼 패널 인터랙션 및 실시간 정확도 측정
* **좌측 영상 패널**: 88올림픽 선수 영상과 함께 해당 경기의 제목, 선수명, 종목, 한줄 설명 텍스트를 제공합니다[cite: 1].
* **우측 웹캠 패널**: 사용자의 웹캠 화면 위에 실시간으로 스켈레톤(관절 포인트)이 오버레이됩니다[cite: 1].
* **실시간 정확도 피드백**: 두 포즈 벡터 간 유사도를 계산하여 우측 패널 상단에 0~100% 형태의 실시간 정확도를 표시합니다[cite: 1].

### 2. 메타데이터 기반 스마트 검색 및 필터링
* 구조화된 API 필드(종목명, 경기분류, 참가국 이름, 구간타이틀명)와 파싱된 텍스트(선수명/키워드)를 기반으로 원하는 경기 클립을 검색할 수 있습니다[cite: 1].

### 3. 콘텐츠 기반 추천 (Recommendation)
* **속성 기반 추천**: 현재 시청/플레이한 클립과 비슷한 종목명, 경기분류, 참가국을 가진 경기를 추천합니다[cite: 1].
* **텍스트 유사도 기반 추천**: 파싱된 경기 설명 텍스트를 분석하여 내용이 비슷한(예: 극적인 역전승 등) 관련 경기를 캐러셀 형태로 제안합니다[cite: 1].

### 4. 결과 요약 및 피드백
* 경기 클립 종료 후 평균 점수, 등급(S/A/B/C)을 산출하여 제공합니다[cite: 1].
* 다음 도전 추천 클립 목록과 다시하기 기능을 지원합니다[cite: 1].

## 📊 공공데이터 활용 전략

본 프로젝트는 공공데이터를 실질적으로 활용하기 위해 다음과 같은 고도화된 데이터 파이프라인을 구축했습니다.

* **메타데이터 중심의 데이터 소비**: API가 제공하는 원본 동영상의 도메인 만료로 재생이 불가한 점을 극복하기 위해, 영상 자체보다는 API의 **메타데이터(종목명, 경기명, 경기 설명 등)를 검색 및 추천 로직의 핵심 엔진**으로 활용했습니다[cite: 1].
* **텍스트 파싱 파이프라인**: 제목명 및 상세내용을 정규식과 키워드 매칭으로 파싱하여 선수명, 연도, 요약설명 등을 추출하고 정적 JSON으로 구축했습니다[cite: 1].
* **콘텐츠 매핑 DB 구축**: 클립 ID를 기준으로 API 메타데이터와 자체 편집/리호스팅한 88올림픽 영상을 연결하는 매핑 테이블을 구성하여 서비스의 핵심 DB로 사용합니다[cite: 1].

## 🚀 실행 방법 (Getting Started)

> 아래 명령은 모두 **프로젝트 루트**에서 실행한다 (`data/` 스크립트도 동일한 기준).

```bash
# 1. 의존성 설치
pip install -r backend/requirements.txt

# 2. 데이터 수집 - backend/.env 에 PHOTO_API_KEY 가 필요하다.
#    이 단계를 건너뛰면 data/olympics.db 가 없어 모든 검색 API가 실패한다.
python data/collector.py

# 3. 백엔드 서버 실행 (http://127.0.0.1:8000)
uvicorn backend.main:app --reload
```

`backend`는 파이썬 패키지이므로 **반드시 루트에서 `backend.main:app` 형태로 실행**한다.
`backend/` 안으로 들어가 `uvicorn main:app`으로 띄우면 패키지 상대 import가 깨져
`attempted relative import with no known parent package` 오류가 발생한다.

프런트엔드는 정적 파일이라 `frontend/`를 아무 정적 서버로 열면 된다
(웹캠 권한 때문에 `file://`이 아니라 `http://localhost`로 열어야 한다).

```bash
python -m http.server 5500 --directory frontend
```

데이터 파이프라인(수집 → 클립 다운로드 → 포즈 추출)의 자세한 사용법은
[data/DATA_PIPELINE.md](data/DATA_PIPELINE.md)를 참고한다.

## ⚙️ 포즈 유사도 측정 알고리즘

본 서비스의 핵심인 동작 일치율은 다음과 같은 과정으로 계산됩니다.

1. **사전 추출**: 기준(선수) 영상의 프레임별 관절 좌표 시퀀스를 미리 분석하여 JSON 데이터로 저장합니다[cite: 1].
2. **벡터 정규화**: 웹캠에서 추출된 사용자의 관절 좌표를 바운딩 박스 기준으로 스케일 정규화 및 L2 정규화(단위 벡터화)하여 자세의 방향만을 비교합니다[cite: 1].
3. **유사도 계산**: 정규화된 두 벡터 간 **코사인 유사도**를 구하며, 신뢰도(Confidence)가 낮은 관절 포인트는 가중치를 낮춰 오탐을 완화합니다[cite: 1].
4. **타이밍 보정**: 사용자의 동작 타이밍 오차를 허용하기 위해 일정 시간 윈도우 내에서 가장 유사한 프레임을 매칭(DTW 또는 슬라이딩 윈도우)합니다[cite: 1].
